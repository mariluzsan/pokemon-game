# Definition of Done

Una funcionalidad está terminada cuando:
- cumple requerimiento y criterios de aceptación;
- respeta la arquitectura;
- el código está en el módulo correcto;
- las reglas críticas permanecen en backend;
- pasan las pruebas aplicables;
- se cubren errores relevantes;
- se revisa seguridad;
- no existen secretos versionados;
- la documentación afectada está actualizada;
- el uso relevante de IA durante desarrollo queda registrado;
- se revisa `git status`;
- el commit representa una unidad lógica clara.

Que una pantalla funcione visualmente no es suficiente para considerarla `Done`.
