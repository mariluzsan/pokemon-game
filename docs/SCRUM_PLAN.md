# Plan Scrum

## Sprint 0 — Fundación
Repositorio, documentación, herramientas, estructura, frontend base, backend base, configuración y PostgreSQL.

## Sprint 1 — Juego principal / MVP
Partidas, Pokémon, reto visual, temporizador, intentos, scoring y resolución.

## Sprint 2 — Hints + IA
Pistas, LLM, validación de spoilers, límites, penalizaciones y fallback.

## Sprint 3 — Dificultad adaptativa
Desempeño, nivel, dificultad adaptativa y selección por dificultad.

## Sprint 4 — Ranking
Persistencia, consulta, orden y pantalla de ranking.

## Sprint 5 — Hardening
QA, pruebas, seguridad, errores, documentación y revisión final.
