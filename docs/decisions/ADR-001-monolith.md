# ADR-001 — Modular Monolith

**Estado:** Aceptado

## Contexto
El proyecto tiene varias capacidades relacionadas y un alcance acotado.

## Decisión
Usar un **Modular Monolith** con módulos de dominio separados.

## Consecuencia
Se reduce complejidad operacional y se mantiene separación de responsabilidades sin introducir microservicios innecesarios.
